# 时刻

**时刻**是一款 Windows 本地任务时间工作台，包含任务计时、番茄钟、每日目标、便签和时间统计功能

## 安装和启动

发布后的单文件程序名为 `Shike.exe`，下载后直接双击运行；无需单独安装 Python。当前仓库保存源码和构建文件，开发者可参阅 [BUILD.md](BUILD.md) 自行构建。

关闭主窗口后，程序继续留在 Windows 通知区域；可以从通知区域重新打开主窗口、开关悬浮窗、打开便签或退出。若提示程序已运行，请在通知区域找到“时刻”图标。

## 功能模块

### 今日

- 为任务开始、停止或切换计时；同一时间只运行一个任务计时。
- 一行时间轴用颜色展示当天各任务的分布。指向色段可查看任务信息，图例说明颜色对应的任务。
- 查看当天各任务的累计时长。
- 用“开工”和“收工”记录一天的工作起止时刻。
- 独立番茄钟可在任务计时中运行，也可单独启动。单独运行的时间记入系统任务“其他”；专注和休息都连续计入当前任务时长。

### 目标

- 按天建立目标，并在目标下添加子待办；可将目标关联到任务。
- 分别勾选子待办和目标。子待办全部完成时会弹出提示和礼花，目标仍需手动标记完成。
- 单击文字展开或收起较长内容；双击或使用“编辑”修改。可删除目标；删除目标会一并删除其子待办，已有计时记录保留。

### 任务

- 建立任务文件夹，为任务设置颜色；可将任务拖到其他文件夹。
- 选择任务或文件夹查看历史计时记录与柱状图：一周内每天、一个月内每周、或一年内每月的时长。
- 统计范围可按周、月、年切换。
- 可归档、恢复或删除任务。归档任务从常规列表隐藏，在页面底部的归档入口查看。删除普通任务会同时删除其历史计时记录；清空系统任务“其他”会删除它的记录，但保留该任务本身。

### 便签

- 用自由文本记录想法，并在便签下添加可勾选的候选条目；便签可以归到某个目标或留在收集箱。
- 单击正文或条目可展开、收起；双击可编辑。已完成便签会显示提示礼花；可归档、恢复或删除。归档便签在页面底部的归档入口查看
- 点击标题栏“快速便签”，或用默认快捷键 `Ctrl+Alt+N` 立即记录，或使用悬浮球召唤便签。快捷键可在设置中修改；快捷键召唤的便签显示在最前面，便签对话框有单独的置顶图钉。

### 设置

- 切换白天／黑暗模式，调整强调色、透明度，以及悬浮窗显示和透明度。
- 调整番茄钟的专注、短休、长休时长和进入长休的轮数；可开关每段结束时的提示音。修改后点击“保存”，下次启动番茄钟时生效。
- 修改快速便签快捷键，设置开机自启动，指定本地数据目录。
- 备份完整数据库，或将时间记录导出为 CSV。

## 悬浮球与窗口

悬浮球可置于其他窗口上方，拖到屏幕左右侧边会半收起；移入后可查看常用任务并快速开始或停止计时。番茄钟运行时，悬浮球变为带阶段进度与倒计时的小钟表。主窗口标题栏的图钉可独立切换主窗口置顶，窗口可拖动边缘改变大小，较长页面可纵向滚动。

## 数据保存与隐私

默认数据库位于 `%LOCALAPPDATA%\TaskTimeDesk\tasktime.db`。可在“设置 → 本地数据”更改目录；程序使用 SQLite 备份方式复制数据，并保留旧目录。更换电脑前，建议在设置中备份数据库，或复制完整的数据文件。

程序仅面向 Windows，不提供账号、云同步或网络功能。Python 异常详情保存在数据目录下的 `crash.log`或者 `fatal-crash.log`
